# Поиск аниме — современный онлайн плеер
Удобный и быстрый веб-клиент для поиска и просмотра аниме, дорам и азиатских сериалов с использованием Kodik API.
Чистый минималистичный дизайн, встроенный плеер, отличная адаптивность и никаких лишних элементов — всё для комфортного просмотра.

✨ Возможности

Моментальный поиск по названию
Встроенный плеер Kodik (без перехода на другие вкладки)
Полностью адаптивный дизайн — отлично работает на смартфонах, планшетах и ПК
Пагинация результатов
Автоматическая фильтрация дублей тайтлов
SEO-оптимизация
Работает без регистрации и рекламы

🎯 Для кого подойдёт

Любителям минималистичного и удобного интерфейса

# Anime Search — Modern Online Player
A fast and convenient web client for searching and watching anime, doramas, and Asian series using the Kodik API.
Clean minimalist design, built-in player, excellent responsiveness, and no unnecessary elements — everything for comfortable viewing.

✨ Features

Instant search by title
Built-in Kodik player (no redirects to other tabs)
Fully responsive design — works great on smartphones, tablets, and PCs
Pagination support
Automatic duplicate filtering
SEO optimized
No registration or ads

🎯 Who is it for

Those who want to quickly find and watch their favorite anime or dorama
Fans of clean and user-friendly interfaces
Users who frequently watch anime on mobile devices

🛠 Technologies

HTML5, CSS3, Vanilla JavaScript
Tailwind CSS
Kodik API
