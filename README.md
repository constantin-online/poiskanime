# Поиск аниме — современный онлайн плеер
Удобный и быстрый веб-клиент для поиска и просмотра аниме, дорам и азиатских сериалов с использованием Kodik API.
Чистый минималистичный дизайн, встроенный плеер, отличная адаптивность и никаких лишних элементов — всё для комфортного просмотра.

✨ Возможности

Моментальный поиск по названию
Встроенный плеер Kodik (без перехода на другие вкладки)
Полностью адаптивный дизайн — отлично работает на смартфонах, планшетах и ПК
Пагинация результатов
Автоматическая фильтрация дублей тайтлов
SEO-оптимизация
Работает без регистрации и рекламы

🎯 Для кого подойдёт

Тем, кто хочет быстро найти и посмотреть любимое аниме или дораму
Любителям минималистичного и удобного интерфейса
Тем, кто часто смотрит аниме на телефоне

🛠 Технологии

HTML5, CSS3, Vanilla JavaScript
Tailwind CSS
Kodik API
